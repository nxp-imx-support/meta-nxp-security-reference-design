Security Reference Design
=========================

.. note::

    The Security Reference Design is released on a once-per-year schedule.

.. note::

    All reference implementations are for development purposes only. Users must ensure that proper security policies and guidelines are followed when handling security-critical material.

The NXP **Security Reference Design** initiative aims to help customers enable and configure security features through the Yocto build process. This framework is designed to simplify enabling and customizing security features on NXP processors.
The following sections describe the features available as part of the Security Reference Design framework.
